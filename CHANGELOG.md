# Changelog

TAK5 theme versions for the WiFi Pineapple Pager. Newest first.

## 1.0.0
- First public release: TAK5, a tactical coyote-tan theme for the Hak5 WiFi Pineapple Pager, with the TAK.5 shield and Tac-Pine.
- **TAK THE PLANET!** boot finale.
- **Eight matching ringtones** (`.rtttl`) for the Pager's ringtone slots.
- Downloads on the release: the theme, the ringtones and the art.
- Developed and tested on Pager firmware 2.0.0-stable.
